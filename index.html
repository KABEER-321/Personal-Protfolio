Background

Practical engineering & genuine curiosity

How I approach software development, what I have built, and what I am learning next.

I am a final-year Computer Science Engineering student at SDM College of Engineering and Technology, Dharwad. I started building web software because I wanted to understand how backend architectures actually function behind the scenes — from session authentication and database indexing to API serialization.

Instead of building trivial toy demos, I look for real administrative and developer friction points. In college, noticing how attendance recording and parent notifications were scattered across manual rosters led me to architect SmartCampus ERP. Building it taught me how to enforce strict role-based access control across four distinct user groups in Django, organize relational schemas, and ground Google Gemini AI responses in college documents using RAG.

Similarly, troubleshooting cryptic compiler errors in programming labs prompted me to build AI Bug Solver to break error traces down into structured, pedagogical explanations. I believe in writing readable, maintainable code with zero unnecessary dependencies, and I am actively preparing for full-time entry-level software engineering roles and internships.
