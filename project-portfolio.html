Personal Developer Portfolio

Lightweight, accessible developer portfolio built with semantic HTML5, custom CSS3 & vanilla JavaScript

Semantic HTML5 Custom CSS3 Vanilla JS (ES6+) GitHub REST API FormSubmit AJAX
View Homepage GitHub Repository
Overview

Executive Summary

This portfolio itself was designed and implemented from the ground up to present my technical journey, academic credentials, and hands-on projects in a clear, credible, and recruiter-friendly format. Moving away from flashy template gimmicks, it embraces a modern technical editorial aesthetic inspired by technical documentation, academic journals, and minimalist developer sites.

The architecture is intentionally zero-dependency: pure semantic HTML5, clean modular CSS3 with design tokens, and modular ES6+ JavaScript. This guarantees near-instant page loads, zero framework maintenance churn, and robust mobile reliability.

Design Philosophy

Developer portfolios often suffer from excessive neon animations, floating particles, and percentage-based skill meters that communicate template usage rather than engineering judgment. The goal here was restraint: high-contrast typography, generous whitespace, honest presentation, and substantive case studies.

Technical Implementation

Constructed using CSS custom properties for typography scales and colors, CSS Grid and Flexbox for fluid responsiveness across viewports from 320px to 1440px+, and asynchronous JavaScript for live GitHub API fetching and FormSubmit handling.

Features

Key Technical Features

Mobile-First Responsiveness

Carefully audited at 320px, 375px, 768px, 1024px, and 1440px widths to eliminate horizontal overflow and awkward wraps.

Editorial Typographic Hierarchy

Harmonious pairing of Newsreader serif for expressive display headings, Plus Jakarta Sans for UI copy, and JetBrains Mono for technical tags.

Zero-Framework Architecture

Zero node_modules, zero bundlers, and zero bloated JavaScript libraries. Pure native web technologies delivering sub-second paint times.

Accessible PDF Modals

Embedded PDF viewers for resume and certificates with automatic mobile fallback to native browser viewing and downloads.

GitHub REST API Integration

Asynchronously fetches real-time public repositories directly from GitHub's REST API with safe DOM insertion.

AJAX Contact Form

Integrated FormSubmit submission with client-side validation, honey-pot anti-spam detection, and inline status feedback.

Engineering Insights

Challenges & Solutions

Challenge

Mobile PDF Rendering Incompatibilities

Mobile browsers (specifically iOS Safari and mobile Chrome) routinely fail to display embedded PDF iframes, resulting in grey blank boxes.

Solution

Feature-Detected Fallback Container

Added programmatic feature detection (`navigator.pdfViewerEnabled` and userAgent checks) to conditionally switch between the inline iframe and an accessible mobile fallback banner.

Challenge

Preventing Horizontal Scroll on Narrow Viewports

Deep heading words, unconstrained iframe elements, and rigid grid layouts frequently trigger horizontal scroll on 320px–375px mobile screens.

Solution

Fluid Clamp Typography & Box-Sizing Discipline

Configured `clamp()` on title font sizes, enabled `overflow-wrap: break-word`, set global `box-sizing: border-box`, and verified `scrollWidth === innerWidth` across breakpoints.
