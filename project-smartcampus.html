Context

Executive Summary

SmartCampus ERP Portal is a full-stack academic management platform designed to digitize and organize campus operations. Developed with Python and Django, the system addresses common communication and administrative bottlenecks across college departments by providing dedicated, role-based dashboards for students, faculty, parents, and administrative staff.

To enhance everyday utility, the portal incorporates Google Gemini API integration configured with Retrieval Augmented Generation (RAG) principles, enabling stakeholders to query institutional regulations, schedules, and academic FAQs through an interactive campus assistant.

The Problem

Academic institutions frequently suffer from fragmented tools: attendance recorded on physical paper registers, grades maintained in disconnected spreadsheets, delayed parent notifications, and repetitive administrative queries that overwhelm college offices during exam seasons.

The Engineering Solution

SmartCampus unifies these workflows onto a single relational database schema with Django authentication. Role-based middleware ensures strict data boundaries between roles, while digital registers, timetable modules, and Gemini AI query resolution provide an integrated operational ecosystem.

Key Implemented Features

Student Dashboard

Real-time personal dashboard reporting subject-wise attendance percentages, internal assessment marks, weekly timetables, and notification announcements.

Fast batch-marking interface with automated percentage calculations, low-attendance thresholds (<75%), and export capabilities.

AI Campus Assistant

Integrated Google Gemini conversational bot grounded in college policies and academic calendars for instant query handling.

Engineering Insights

Challenges & Solutions

Challenge

Role-Based Access Control Architecture

Providing 4 distinct perspectives on the same database without leaking sensitive administrative or student data required rigorous authorization modeling.

Solution

Django Authentication Groups & Middleware

Implemented custom Django user models with assigned groups and route-level decorators to verify role memberships before rendering views or returning serialized data.

Challenge

AI Assistant Grounding & Hallucination Prevention

General LLM models often generate plausible-sounding but inaccurate answers when queried about institution-specific rules or semester schedules.

Solution

Structured Prompting & Context Injection

Structured the chatbot pipeline to inject verified institution rules and metadata into the Gemini API prompt context before generating responses, ensuring accurate answers.
