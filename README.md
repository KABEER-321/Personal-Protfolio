# 🌐 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website showcasing my skills, projects, certifications, and experience as a Computer Science Engineering student. The website serves as a central hub where recruiters and developers can learn about my work and connect with me.

🔗 **Live Demo:** https://mohammed-kabeer-portfolio.netlify.app/

---

## ✨ Features

- 🎨 Modern and responsive UI
- 🌙 Dark theme with smooth animations
- 👨‍💻 About Me section
- 🛠 Skills & Technologies
- 📂 Featured Projects
- 📜 Certifications
- 📞 Contact Information
- 📱 Mobile-friendly design
- ⚡ Fast loading and optimized performance

---
